## How it works

`compute_streak(db, config, habit, end_date, user_id)` keeps its exact signature. Internally it now resolves `goal` and `db.get_cadence(...)` once, then picks `_daily_walk` (no cadence row) or `_weekly_walk` (a `habit_cadence` row). Both walks route every date/week through `classify_day`/a week-level equivalent, which returns QUALIFIED (real entry), NEUTRAL (paused or grace-protected, held — doesn't increment, doesn't break), or MISSED (breaks the walk). With the three new tables empty for everyone, `paused_dates`/`grace_protected_dates` are always empty sets, so every day is QUALIFIED-or-MISSED and the daily walk is byte-identical to the pre-v1.9 algorithm. Grace is only ever consulted by the daily walk (a cadence habit never reads `grace_protected_dates` at all, per Rule 6). `streak_unit` reports "week" iff a cadence row exists; no renderer consults it yet (that's integration's job). Migration 012 lays down `habit_cadence`/`grace_ledger`/`pauses` (all additive); the four new config sections default to the spec's stated values (`wrapped.auto_send=false` per the confirmed user decision). `core/fonts.py:register_thai_font()` is called once (idempotent) from each of `charts.py`/`heatmap.py`'s own `MATPLOTLIB_AVAILABLE` import guard, and sets `rcParams["font.family"] = ["DejaVu Sans", "Noto Sans Thai"]` — additive, DejaVu stays primary.

## Known limitations

- **Font is a variable TTF, not a static "Regular" instance.** As of this writing, `github.com/google/fonts` ships Noto Sans Thai only as a variable font (`ofl/notosansthai/NotoSansThai[wdth,wght].ttf`, commit `34b48ab6f74867dbfce19410a2f452abef34e3ff`) — there is no static/hinted build in the repo. I downloaded and renamed it to `NotoSansThai-Regular.ttf` per the spec's asset naming. matplotlib 3.11.1 (installed) resolves this correctly at its default named instance (confirmed empirically — Thai text renders, non-Thai byte-identity holds) via `font_manager.fontManager.addfont`, but this is a materially different artifact than a dedicated static-weight TTF; if a future matplotlib version handles variable-font default-instance resolution differently, re-verify. SHA-256 of the bundled file: `5a1c559bb539583c8a1fd99d1c5b9491e5e14478c9cd2bd0970d5c3096cc9ef8`. OFL.txt SHA-256: `2e98fd23a52d253db8612cd5942c8f2ff4111b21d2367050fdca91d8ccc374a0`. Source: `https://raw.githubusercontent.com/google/fonts/main/ofl/notosansthai/NotoSansThai%5Bwdth%2Cwght%5D.ttf` (blob sha `34b48ab6f74867dbfce19410a2f452abef34e3ff`).
- **Asset path resolution assumes an in-place repo checkout**, mirroring `config.py:REPO_ROOT`'s own existing assumption (this app runs via a Task Scheduler launcher against the live checkout, not a redistributed wheel install elsewhere per PROGRESS.md's ops notes). `pyproject.toml`'s `force-include` entry is present for a hypothetical future wheel build but I did not verify an actual `hatchling` build succeeds (hatchling isn't installed in this dev venv) — the TOML table syntax itself validates cleanly via `tomllib`, but I'm flagging this untested path honestly rather than claiming a build I didn't run.
- **A pre-existing false-positive collision, flagged for module `cadence`**: the reserved stem `กี่ครั้งต่อสัปดาห์` contains `กี่` (one of `_QUERY_PATTERNS`' substring anchors), so it currently dispatches as `"query"`, not `None`, when typed bare — harmless today, but module `cadence`'s own future `_match_cadence` Thai matcher **must** be positioned before the query check in `dispatch()`'s ordering (like every other anchored settings-style matcher already is), or this exact literal will be silently swallowed by query forever. Documented in the test file (`tests/test_v19_shared_surface.py` and `tests/test_commands.py`'s `_RESERVED_WORD_EXPECTED_KIND` comment) so it isn't lost.
- No pushback on Ichi's/Sophia's design — the engine design in SPEC-v1.9.md §4/§5 implemented cleanly with no structural surprises. The one judgment call I made: `_MAX_LOOKBACK_WEEKS = 520` (≈10 years) as the weekly-walk's loop cap, mirroring `_MAX_LOOKBACK_DAYS = 3650`'s own existing precedent (not spec-mandated, but the same "bound a years-old habit's walk" rationale).
- Cadence/grace/pause/wrapped command execution, i18n copy, `/habits`/`/dashboard` rendering, and `/help`/menu updates are all out of scope for this pass — that's the four parallel modules (M1–M4) + integration.

Baseline was 3799/0/1/1xf; this pass leaves the suite at **3901/0/1/1xf**.
